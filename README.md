# ServiceNow Admin Portfolio (Zurich Release)

This repository contains hands-on ServiceNow Admin projects built in a Zurich Personal Developer Instance.  
These projects demonstrate real-world ServiceNow administration skills using upgrade-safe configuration and Flow Designer automation.

---

## 📁 Projects

### 🔹 Project 1: Incident Automation – Security Routing
Automated routing of security-related incidents using Flow Designer based on keyword detection to reduce manual triage.

### 🔹 Project 2: Vulnerability Intake & Remediation
Custom vulnerability intake table with severity-based automation to flag and update critical vulnerabilities.

### 🔹 Project 3: Risk Register & Escalation
Risk tracking solution with automated escalation logic for high-risk entries using Flow Designer.
